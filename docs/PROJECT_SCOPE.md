# Project scope, provenance, and credit

## Academic context

VideoSearcher-AgenticAI was presented in July 2026 as a group project at **Politecnico di Milano**. The submitted presentation names **Stefano Garzoni, Daniel Guarnizo, and Leonardo Scappatura**.

## Included contributions (project-level, not individual attribution)

- Multi-agent orchestration and tool-routing based on OpenAI Agents SDK and the MCP protocol.
- Specialized media-processing tools and vision-language integration points.
- Test specifications, behavioral/ground-truth metrics and the experimental evaluation pipeline.
- Comparative measurements of five local LLM orchestrators, CodeCarbon energy tracking and Bayesian hyperparameter search.
- Presentation slides, charts and technical rationale.

**Important:** Neither the export nor the slides establish a per-person ownership/commit history. Individual authorship is **not asserted** here. Separate/private VLM research code was not developed as part of this distributable snapshot by the present maintainer and is **not included**; see [Private components](PRIVATE_COMPONENTS.md).

## Intellectual property and distribution

The source was provided as a detached archive without prior Git metadata, an approved public license, or a verified third-party redistribution grant. This repository therefore intentionally has **no LICENSE file** and starts private. Do not make it public or redistribute incorporated materials without agreement from contributors and any relevant rightsholders. External models, pretrained weights, fixtures and cited frameworks have their own terms.

## Source integrity

The original package did not contain the two private framework source trees, a complete Git history, model weights, or large fixture videos. Nothing here claims that those artifacts can be recovered. All changes made while preparing the GitHub-ready copy are recorded in [Repository notes](REPOSITORY_NOTES.md).
